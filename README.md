# Base60tok

Stupid simple XFCE GT4 stopwatch.

## Dependencies

```bash
sudo apt install build-essential pkg-config libgtk-4-dev
```

## Installation Steps

```bash
git clone https://github.com/grgorien/base60tok
```

```bash
cd base60tok
```

```bash
make
```

```bash
sudo make install
```

Done.

## Usage

- Start/Stop: Space
- Clear: (Shift + C)
